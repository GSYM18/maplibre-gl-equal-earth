# Handoff: move everything to MapLibre 6.17.x, then port the native blend (from 2026-11-15)

Written 2026-11-10 for a fresh session. Read this file whole before doing anything. It is the
single entry point; everything it names is committed on branch `feature/native-blend` of this
repository unless stated otherwise.

## Why this exists

MapLibre 6.17.0 (published 2026-11-07 23:03 UTC) rewrote camera handling: #8902 "let Map change
the camera only through Camera", #8906 "make the camera's transform read-only outside Camera",
#8961 "refactor camera task scheduling", which **removes `Camera#isEasing`**. This plugin's
camera, constraint and geographic API reach into exactly those internals, and the planned fork
patches the same seams. The user's instruction (2026-11-10): **do the work once, on the newer
version**, so nothing is implemented twice: first for 6.16, then again for 6.17.

The 7-day rule (below) made 6.17.0 unusable before **2026-11-15** (exactly: after
2026-11-14 23:04 UTC). Nothing was changed for 6.16 on purpose.

## Hard rules (the user's, non-negotiable)

1. **No external resource younger than seven days**: npm versions (including transitive ones,
   CVE fixes), CDN URLs (`unpkg`/`jsdelivr` versions), git tags fetched into the fork. `~/.npmrc`
   and the repo's `.npmrc` set `min-release-age=7`; still verify every changed lockfile entry's
   publish date against now − 7 days (`registry.npmjs.org/<name>` → `time[version]`) and every
   hand-picked version.
2. **No `Co-authored-by` trailer** in any commit message, here or in the fork, and no plan text
   telling agents to add one. Say so explicitly in every subagent prompt that commits.
3. **Push only when the user asks**; never publish. Never `git add -f dist/`.
4. **Never commit** the user's uncommitted `demo/umd.html` edits or the untracked
   `docs/Screenshot 2026-10-10 204903.png`. Switch branches without disturbing them (they
   survive a switch between commits with the same `demo/umd.html`; otherwise stash and restore,
   and diff to prove the edits came back byte-identical).
5. **Producing tiles on the SmartMaps side is out of scope** (2026-11-10): no server-side
   Equal Earth tiles, no pre-warped sources; the warp stays in the client. Do not propose it.
6. The user prefers autonomous execution (specs, plans, implementation without check-ins);
   record rulings, ask only real product decisions, batched in one message.

## Gotchas collected

- Windows; many files CRLF. Prefer the Edit tool or scripts that preserve line endings; inline
  heredoc Python sometimes fails in this shell: write scripts to the session scratchpad.
- `python3` is the Windows Store stub and hangs; use `python -I`.
- Installing local git hooks was blocked by the auto-mode classifier; don't retry.
- SwiftShader (headless) is evidence for correctness, never timing.
- Never write `in <word> <word>` in a shader prelude comment (MapLibre's `prepare()`).
- EPSG:8857 is ellipsoidal; our CRS is spherical: they differ by up to ≈0.128° (research §4).
